One short funny line answering the prompt — the excuse a robot vacuum gives after eating a sock. The program writes the line to `/output/entry.txt`. The joke reframes the crime as hospitality: the vacuum denies eating the sock and claims it gave the sock a guided tour of its dustbin, and the sock refused to leave.

## Run it

```sh
python3 main.py
```
